## 一、刀的运动模型（自动，玩家不可控）

每把上阵的刀有**两层旋转**，全部由刀种基础值 + 词缀 + 羁绊决定：

```
        公转（绕玩家）                    自旋（绕自身重心）
     θd = θd0 + ω_orbit·t              θs = θs0 + ω_spin·t
     P_dao = P_player + R·(cosθd, sinθd)
```

| 参数 | 含义 | 决定因素 |
|---|---|---|
| ω_orbit 公转角速度 | 刀绕玩家转的快慢 | 基础 0.6 圈/s，系别（风系+50%）与词缀修正 |
| R 公转半径 | 刀离玩家的距离 | 刀种基础值（轻刀近、重刀远），词缀修正 |
| ω_spin 自旋角速度 | 刀自身翻转 | 刀种基础值（0.5~2.5 圈/s），词缀修正 |
| φ 刀刃朝向 | 刀尖指向 | 自旋累积角 + 公转切向偏置（默认刀尖指向运动方向，即"甩鞭"姿态） |

**多刀相位分布**：第 i 把刀的公转初相 θd0 = 2π·i/n（n 为上阵刀数），保证刀阵均匀覆盖。收势后重新均匀分布。

## 二、碰撞判定

刀抽象为**线段（刀身）+ 端点（刀尖）**两段判定：

```
刀尖：P_tip = P_dao + L·0.5·(cosφ, sinφ)
刀身：线段 [P_dao − L·0.3·u, P_tip]，宽度 w
```

- **刀身命中**：线段-圆相交（敌人圆）。伤害系数 1.0。
- **刀尖命中**：P_tip 与敌人圆心距离 < r+0.1。伤害系数 1.6（见 [伤害公式](./03-伤害公式.md)）。
- **命中冷却**：同一把刀对同一敌人两次判定间隔 ≥ 0.4s（防止贴脸复读）。
- 玩家与刀无碰撞（刀不伤主）。刀与刀之间仅在"弹刀"词缀下交互（互相弹开，演出用）。

## 三、物理表现层（手感向，可调）

| 表现 | 触发 | 效果 |
|---|---|---|
| 弹开 | 刀命中高护甲敌人（DR≥60%） | 刀瞬间偏转 30° 并短暂加速，音效"铛" |
| 卡刀 | 命中时敌人死亡 | 刀短暂减速 0.2s（收割顿挫感） |
| 格挡 | 刀命中盾兵正面 120° 扇区 | 伤害为 0，火花特效，刀大幅弹开 |
| 拖尾 | ω_spin > 1.5 圈/s | 刀光拖尾，纯视觉 |

> 物理表现**不改变伤害数值**（除格挡归零），只为手感服务。

## 四、收势（唯一"大招"，全自动）

```
能量机制：收势能量 0~100
  充能：+12.5/s 基础（风系羁绊、词缀可提升）
  触发：能量=100 时自动释放，不可攒不用

收势演出（总 1.0s）：
  T+0.0~0.5s 收拢：全部刀向玩家收拢（半径 R→0.5），期间无敌帧（仅前 0.3s）
  T+0.5s 炸开：以玩家为圆心的环形冲击波（半径 3 单位扩张至 6 单位）
    伤害 = 全部刀的刀尖伤害之和 × 2.0（属性按主系别计算）
    击退：范围内敌人击退 2 单位
  T+0.5~1.0s 归位：刀均匀弹回各自公转轨道，能量清零
```

**设计意图**：收势自动释放 = 操作零负担，但**走位决定炸点**——把怪聚到身边再让收势炸，是仅左键操作下的"操作天花板"。

## 五、词缀/羁绊如何改写上述参数

| 修改维度 | 词缀示例 | 羁绊示例 |
|---|---|---|
| ω_orbit | 迅影 +15% | 风 2 件：全体公转 +25% |
| R | 长驱 +15% | 风 4 件：半径 +30% |
| ω_spin | 疾风 +15% | — |
| 刀尖/刀身占比 | 前倾/后坐 | — |
| 收势 | 蓄能/瞬发/惊蛰 | 雷 2 件：收势附加雷链 |

> 全量词缀见 [刀词缀库](../04-build/01-刀词缀库.md)，羁绊见 [羁绊与连携](../04-build/03-羁绊与连携.md)。
