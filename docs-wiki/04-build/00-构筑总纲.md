## 构筑 = 三要素

```
构筑（Build）
 ├── ① 刀阵编队：负重预算内选哪些刀（自走棋"棋子"）
 ├── ② 词缀配置：每把刀的 affix（爬塔中获得/局外重铸）
 └── ③ 系别羁绊：同系刀达 2/4 件触发（自走棋"羁绊"）
```

玩家的一切强度来自这三层组合，**不来自操作**（操作仅左键走位）。

## 负重预算（构筑的第一约束）

| 境界 | 负重 | 典型编队示例 |
|---|---|---|
| 学徒 | 6 | 柳叶×2 + 青竹×2 + 燕翎×1（5 斤，留 1 斤） |
| 铸师 | 10 | 断骨 + 蜈蚣 + 寒月 + 柳叶×2（8 斤） |
| 名匠 | 15 | 惊雷 + 断骨 + 蜈蚣 + 燕翎×2（13 斤） |
| 宗师 | 21 | 镇岳 + 惊雷 + 血饮 + 蜈蚣 + 寒月（18 斤） |
| 刀圣 | 28 | 橙×2 + 紫×2 + 蓝×2（约 26 斤） |
| 至尊 | 36 | 全橙紫自由配 |

**核心张力**：
- **量 vs 质**：多把 1 斤轻刀（触发频率、羁绊件数、相对速度加成）vs 少把 5 斤重刀（单次质量、压制光环）。
- **同 vs 杂**：同系吃羁绊（风 4 件套）vs 混系吃克制（针对域敌人配属性）。

## 编队规则

1. 上阵刀数无上限，仅受总重 ≤ 负重约束。
2. 同名刀可重复上阵（两把"断骨刀"OK），但合成需要 3 把同名同阶（见合成）。
3. 局内获得的刀即时入阵（若负重允许）；超重则进背包待局外处理。
4. 局内可以**随时**在非战斗节点调整编队（战斗内锁定）。

## 局内 vs 局外的构筑变化来源

| 来源 | 时机 | 内容 |
|---|---|---|
| 局外锻造 | 铁匠铺 | 造新刀、淬火重铸词缀 |
| 局外淬体 | 铁匠铺 | 提负重（= 局外最大成长轴） |
| 局内商店 | 商店节点 | 买刀、买词缀（临时，本局有效） |
| 局内事件 | 事件节点 | 增/换/复制刀、词缀 |
| 局内合成 | 随时（满足条件提示） | 3 合 1 升阶 |
| 局内祭坛 | 祭坛节点 | 词缀强化/刀升重（代价类） |

> 设计意图：局外决定"流派骨架"，局内完成"随机补完"——自走棋的快乐 = 抽到棋子凑羁绊。

## 构筑强度自检（与 [伤害公式自检表](../03-combat/03-伤害公式.md) 联动）

任何流派 build 必须满足：
1. 学徒期（6 斤）即可起步雏形（前 3 把刀能买到/掉到）。
2. 有明确"成型点"（哪 2-3 件到位即质变）。
3. 有明确克制关系（被某域敌人/词条克制，无全能解）。
