## 一、技术栈（v1.2 定稿：Vite + TS + Canvas2D）

| 项 | 选型 | 说明 |
|---|---|---|
| 构建 | Vite 5 | `npm run dev` 即游戏页 |
| 语言 | TypeScript 5（strict 全开） | 构建前 `tsc --noEmit` 全量类型检查 |
| 渲染 | Canvas 2D | 俯视 2D，固定时间步长主循环，目标 60fps |
| 框架 | 无 | 不引入 UI/游戏框架，场景与实体自研轻量结构 |
| 存档 | localStorage（M6） | 键名 `zdzzq_save_v1` |
| 数值校验 | `tools/m1-sim.ts`（M1 已落地雏形）→ `tools/balance-harness/`（M7 完整版） | 纯 TS 模拟器，见 [数值优化方案 §十二](../09-report/数值优化方案.md) |

## 二、代码架构

```
zhuandaozizouqi/                # 仓库根 = 游戏工程
├── docs-wiki/                  # 设计 Wiki（本目录）
├── index.html                  # 唯一页面（全屏画布）
├── src/
│   ├── main.ts                 # 入口：数据校验 → 装配 Game → 启动
│   ├── core/                   # Game 主循环 · Input（仅左键）· Camera · Rng · math
│   ├── data/                   # 07-content 数据镜像 + 全局常量 + 一致性校验
│   ├── combat/                 # ✅M1：刀实体/碰撞/伤害公式/战斗世界/空间哈希；M2+：敌人AI/飞行物
│   ├── render/                 # ✅M1：特效池（伤害数字/火花）；M3：预警圈等
│   ├── scenes/                 # 场景：木桩测试场(M1) → 战斗(M2) → 节点地图(M4) → 铁匠铺(M6)
│   └── ui/                     # M4+：仅左键 UI 组件（可交互元素 ≥48×48px）
└── tools/
    ├── m1-sim.ts               # ✅M1：DPS 模拟雏形（balance-harness 前身）
    └── balance-harness/        # M7：完整数值模拟器（5 类测试桩 / P10-P90 分布输出）
```

**数据流**：`07-content 四清单 → src/data/*.ts（人工同步）→ 运行时`。

改数值**必须**先改 wiki 清单，再同步 `src/data/`；`src/data/` 以外的文件禁止出现战斗数值字面量（表现层配色等非数值常量除外）。

## 三、工程红线（设计红线的技术化）

1. **仅左键**：`Input` 只暴露左键按住状态、指针世界坐标、左键点击队列；任何场景不得读取其余输入。ESC 暂停仅作兼容，不作为必须路径。
2. **60fps 预算**：同屏敌 ≤40 / 刀 ≤8 / 飞行物 ≤60 / 粒子 ≤200；碰撞走空间哈希网格（cell=1.0）。
3. **单位约定**：世界单位 u（1u=64px 基准）；速度 u/s；转速 圈/s（代码内 ×2π 转弧度）。
4. **数据可溯源**：刀/敌/Boss/事件/词缀 ID 必须能在 07-content 或词缀库溯源；新增内容先改 wiki 再写代码。
