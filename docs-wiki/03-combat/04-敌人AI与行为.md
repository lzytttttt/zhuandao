## 一、通用行为树

```
[入场] ──► [索敌]（锁定玩家）
             │
             ▼
        [行为循环]（每 0.2s 决策一次）
             │
   ┌─────────┼──────────┬─────────────┐
   ▼         ▼          ▼             ▼
[移动]   [攻击前摇]  [攻击]      [受击反应]
 追击     ≥0.5s 演出  生效/被闪   硬直/击退
```

**通用规则**：
1. 所有攻击**前摇 ≥0.5s**（红色警示圈/抬手演出），保证走位可躲。
2. 敌人移速全部 **低于** 玩家基础移速（6 u/s）的 90%，走位永远可行。
3. 敌人不叠加碰撞体（彼此穿过），仅对玩家有推挤。
4. 普通敌人无血条，精英/Boss 有顶部血条。

## 三、精英与词缀怪（局内变化）

- 精英 = 普通敌人 × **1 个精英词条**（血量×3、攻击×1.5、体型×1.2、金圈标识）。
- 精英词条池（MVP 6 个）：

| 词条 | 效果 |
|---|---|
| 迅捷 | 移速 +40% |
| 石肤 | 护甲 +60 |
| 狂暴 | 血量 <30% 时攻速 +50% |
| 分裂 | 死亡时分裂 2 只小体（血量 25%） |
| 吸血 | 攻击回自身血 50% |
| 屏障 | 每 10s 获得一层 30 点护盾 |

## 四、索敌与包围智能（防"死角挂机"）

1. 敌人以玩家为圆心做**松散包围**（目标点 = 玩家位置 + 均匀角度偏移），而非全部叠在玩家脸上。
2. 远程敌人（T5/T6/T10）会**主动撤退**保持射程（玩家逼近时后撤）。
3. T3 冲锋兵在玩家静止超过 2s 时优先触发冲锋——惩罚挂机，奖励走位。

## 五、Boss 通用规则

- 多阶段（各 Boss 2-3 阶段），转阶段演出 1.5s（无敌+清屏子弹）。
- 每阶段 = 行为池轮换（见 [BOSS设计](../05-tower/03-BOSS设计.md)）。
- Boss 房固定竞技场，无杂兵波次（除召唤类技能）。
