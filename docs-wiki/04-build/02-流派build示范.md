## 1. 龙卷风流（教学流·爽感担当）

| 阶段 | 编队（重量） | 说明 |
|---|---|---|
| 学徒 | 柳叶×2 + 飞蝗 + 青竹（4 斤） | 风 2 件套已触发（风刀公转+20%） |
| 铸师 | + 燕翎×2（8 斤） | 4 把风刀，半径初见规模 |
| 名匠（成型） | 柳叶/飞蝗换青霜 + 燕翎（≤15 斤） | 风 4 件：半径+30%、命中冷却-0.1s |

- **手感**：刀光连成环，走到哪刮到哪，相对速度加成吃满。
- **克星**：域 4 高甲（刮不动）→ 需补破甲词缀或换流。
- **关键词缀**：长驱 II、迅影 II。

## 2. 烈焰环流（站桩流·新手友好）

| 阶段 | 编队 | 说明 |
|---|---|---|
| 学徒 | 火褶×2 + 柳叶×2（6 斤） | 火 2 件：火刀攻击+10%、附灼烧 |
| 铸师 | + 火褶×1（同名单卡） | 灼烧层数滚动 |
| 宗师（成型） | 血饮 + 火褶×2 + 断骨 + 寒月（≤21 斤） | 血饮把灼烧变回血，站撸成立 |

- **手感**：伤害延时结算（DoT），走位容错极高。
- **克星**：域 3 高机动水贼（灼烧打不满）。
- **关键词缀**：燃刃、汲血。

## 3. 蚀骨毒环（滚雪球流）

| 阶段 | 编队 | 说明 |
|---|---|---|
| 铸师 | 毒烟×2 + 蜈蚣 + 寒月（7 斤） | 毒 2 件：叠层上限 7 |
| 名匠（成型） | 蜈蚣×2 + 毒烟 + 寒月 + 燕翎（12 斤） | 中毒 7 层 ×10%/s 全场滚 |
| 宗师 | + 血饮（火，吃毒伤吸血不行——毒火分工） | 换断骨，毒尸爆清理蜂群 |

- **手感**：前期疲软，Boss 战叠满后 DPS 曲线陡升。
- **克星**：域 5 刀傀自爆（来不及叠层就贴脸）。
- **关键词缀**：淬毒、破甲（补前期）。

## 4. 金刚裂山流（重刀流·一击必杀）

| 阶段 | 编队 | 说明 |
|---|---|---|
| 铸师 | 断骨 + 青竹×2（5 斤） | 刚 2 件：攻击+18% |
| 宗师（成型） | 镇岳 + 断骨×2 + 青竹（14 斤） | 刚 4 件：击退+0.5、无视 30% 甲 |
| 刀圣 | + 玄铁重刀（对盾钥匙）（≤28 斤） | 压制光环 + 巨刃击退，域 4 亲爹 |

- **手感**：慢但每一下都是地震，收势炸=核爆（单刀质量大）。
- **克星**：域 2 盾卫正面格挡（需玄铁重刀破局）、蜂群绕背。
- **关键词缀**：压重、后坐（刀身流）、震荡。

## 5. 惊雷九霄（暴击流·欧皇时刻）

| 阶段 | 编队 | 说明 |
|---|---|---|
| 铸师 | 闪电×2 + 惊雷 + 柳叶（7 斤） | 雷 2 件：雷刀暴击+12% |
| 名匠（成型） | 惊雷 + 闪电×2 + 燕翎×2（11 斤） | 高频小刀狂触发暴击→雷链 |
| 刀圣 | 惊雷×2 + 闪电×2 + 雷鸣 + 青霜（16 斤） | 雷 4 件：全阵暴击共享雷链 |

- **手感**：屏闪雷鸣，数字乱跳，方差大。
- **克星**：非酋（暴击不出）→ 词缀"剑鸣"补底。
- **关键词缀**：剑鸣、断金、引雷。

## 6. 两仪归一（终局构筑·规则流）

| 阶段 | 编队 | 说明 |
|---|---|---|
| 刀圣（起步） | 两仪 + 玄铁 + 燕翎×2（14 斤） | 玄系规则刀 + 风 2 速度 |
| 至尊（成型） | 两仪 + 镇岳 + 青霜 + 玄铁 + 蜈蚣（≤36 斤） | 每把都是规则刀/橙刀，无羁绊依赖但每把自 carry |

- **手感**：相位满（两仪占 2 相位）、格挡无视、领域压制、风暴刮削——六边形战士。
- **定位**：通关构筑天花板，毕业答案之一（非唯一）。
- **关键词缀**：瞬发（两仪专属）、震荡。

## 平衡自检结论（设计目标）

- 每套流派都能**从学徒/铸师起步**，在**名匠~宗师成型**，通关黑风崖。
- 每套流派都有**明确克星域**，逼玩家局内补词缀或换刀（肉鸽决策）。
- 6 套覆盖：快攻/DoT/滚雪球/重击/暴击/规则 六种正交体验。
