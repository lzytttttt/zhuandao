## 结构

"塔"即**江湖五大域**（v1.1 决策 #4：世界分域替代抽象层数）：

```
铁匠铺（局外）
   │ 告示牌选域
   ▼
域（一局爬塔）
   │ 3-5 个节点（随机路线）
   ▼
域尾 BOSS ──胜──► 声望结算 → 回铁匠铺（解锁下一域）
   │败
   ▼
死亡结算（build 清空 / 材料 50% 保留）→ 回铁匠铺
```

## 一局 = 一域

- **单局时长**：30-60 分钟（普通域）/ 60-90 分钟（域 5）。
- **单局边界**：进域时以当前刀架编队为初始 build；局内获得即时生效；出域（无论胜败）回铁匠铺。
- **重复刷域**：永远可行（材料/词缀/图鉴需求），低域掉率不衰减。

## Roguelike 随机性清单（每局随机的内容）

1. 节点类型序列（战斗/事件/商店/祭坛/休息/精英）
2. 战斗内敌人波次组合
3. 敌人精英词条（见 [敌人AI](../03-combat/04-敌人AI与行为.md)）
4. 商店货架 & 事件选项
5. 掉落（金币区间、材料种类、刀掉率）

**不随机**：域顺序、Boss 机制（固定招式池）、词缀数值（固定档位）、刀面板。

## 失败与重开节奏

- 域 1-2：死亡损失小（5 分钟一局），鼓励试错。
- 域 3-4：死亡损失中（30 分钟），材料 50% 结算兜底。
- 域 5：死亡损失大但声望积分结算（终域特殊：按到达节点数给声望，见 [声望](../06-progression/03-声望与江湖.md)）。
