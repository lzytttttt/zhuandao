# 声望与江湖

> 上级：[成长总纲](./00-成长总纲.md)

---

## 声望是什么

- 江湖地位数值（永久），**解锁进度的钥匙**（域 + 淬体门槛）。
- 不直接加战力（战力唯一来源 = 负重/刀/词缀）。

## 声望来源

| 来源 | 数值 | 说明 |
|---|---|---|
| 击败普通敌人 | +1 | 积少成多 |
| 击败精英 | +10 | |
| 通关节点 | +5 | |
| 事件（拜别/听故事等保守选项） | +50~200 | 见 [事件清单](../07-content/03-全事件清单.md) |
| Boss 首通 | +200~1500 | 大头（见 [BOSS 设计](../05-tower/03-BOSS设计.md) 掉落表） |
| Boss 重复击杀 | +60~300 | 刷声望可行但慢 |
| 域 5 特殊：按到达节点数结算 | 每节点 +20 | 终域失败补偿 |

## 声望解锁表

| 声望 | 解锁 |
|---|---|
| 100 | 域 2（衡岚山）+ 淬体资格（铸师） |
| 250 | 域 3（沧澜水乡）+ 淬体（名匠） |
| 500 | 域 4（大漠孤城）+ 淬体（宗师） |
| 900 | 域 5（黑风崖）+ 淬体（刀圣，另需通关域 4） |
| 1500 | 淬体（至尊，另需击败剑无极） |

> 声望门槛与淬体门槛**共用数值**（同一进度尺），玩家心智简单："声望到了，就能升/能去"。

## 负声望（江湖恩怨）

- 事件"趁乱打劫"等选项：声望 -100。
- 负声望不锁功能（下限 0），但影响：
  - 商店价格 +10%（声望 < 200 时）
  - 游医事件不再出现（声望 < 0 时）
- 设计意图：给"邪派玩法"一点风味，不做硬惩罚。
