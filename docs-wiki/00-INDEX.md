## 全局硬性约定（全 Wiki 生效）

1. **操作红线**：仅鼠标左键。任何设计不得引入键盘/右键/组合键/QTE。
2. **视角**：俯视 2D，平面碰撞。
3. **费用体系**：刀的携带成本统一称**重量（斤）**；上限称**负重**，由境界决定。
4. **属性环**：火克刚 → 刚克风 → 风克毒 → 毒克水 → 水克火（克制 +20%，被克 −15%）。
5. **命名唯一**：刀/境界/流派/敌人命名全局唯一，禁止别名。新命名先查 [07-content](./07-content/)。
6. **数值唯一**：所有最终数值以 `07-content` 四张清单为准，其余章节只写规则与公式。
7. **原创**：所有人物/地名/门派均为原创，不得取用现有武侠小说 IP。

## 维护规则

1. **代码引用**：代码里的刀/敌/Boss/事件 ID 必须能从 `07-content` 清单溯源；改数值先改清单，再同步代码。
2. **单一事实**：同一概念只在一个文件描述，其余处用链接。
3. **新系统先立章节**：任何新玩法先写 wiki 章节（用 [_templates](./_templates/)）→ 评审 → 再进开发。
4. **工程档案**：开发进度、技术决策与 wiki 互动记录统一落在 [10-dev](./10-dev/)；开发中发现设计不一致须当场修正或登记开放问题。
