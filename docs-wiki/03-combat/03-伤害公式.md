# 伤害公式

> 上级：[战斗总纲](./00-战斗总纲.md) ｜ 输入数值以 [07-content](../07-content/) 清单为准。

---

## 一、总公式

```
最终伤害 = 基础伤害
         × 部位系数
         × (1 + 相对速度加成)
         × 暴击期望系数（结算时二值）
         × 属性克制系数
         × (1 − 敌方减伤率)
         × 全局难度系数
```

## 二、各项定义

### 1. 基础伤害
= 刀面板攻击力（A_dao）。来源：刀种基础 + 词缀加成 + 羁绊加成。

### 2. 部位系数
| 部位 | 系数 | 条件 |
|---|---|---|
| 刀身 | 1.0 | 线段判定命中 |
| 刀尖 | 1.6 | 端点判定命中 |
- 词缀"前倾"将刀尖系数 +0.2（1.6→1.8）；"后坐"刀身 +0.2 且刀尖 −0.2。

### 3. 相对速度加成（v-damage）
```
速度伤害加成 =
clamp(
  (spin / 1.5 - 1) × 0.16
+ (orbit / 0.6 - 1) × 0.12
+ 玩家有效移动速度 / 6 × 0.08,
  -0.10,
  +0.30
)
```
- 意图：跑动拉扯、刀阵外缘、收势炸开时伤害更高——**走位=增伤**。
- **半径不直接产生伤害收益**（半径已是覆盖/安全/多目标强属性，避免一项属性吃两个乘区）。
- 轻刀（高 spin/orbit）天然吃满此加成，是 1 斤刀走量的隐藏补偿；重刀（低 spin/orbit）吃不到。
- 上限 **+30%**（v1.3 由 +50% 下调，防重刀二次膨胀）。

### 4. 暴击
```
暴击率 C = 0.05（基础）+ 词缀 + 羁绊（上限 0.75）
暴伤 M = 1.5（基础）+ 词缀
期望系数 = C 时取 M，否则取 1（逐次结算，非期望值）
```

### 5. 属性克制系数
| 关系 | 系数 |
|---|---|
| 刀系克敌系 | 1.20 |
| 敌系克刀系 | 0.85 |
| 无关 | 1.00 |
- 环：火→刚→风→毒→水→火。雷/玄与所有系无关（1.00）。
- v1.3 由 1.30/0.80 收为 1.20/0.85（中等难度）：Roguelike 随机掉落下玩家可能无法及时换系，收敛克制差避免"不是难，是根本打不动"。
- 敌人系别见 [全敌人清单](../07-content/01-全敌人清单.md)。

### 6. 敌方减伤
```
护甲减伤 DR = A / (A + 100)          （A=敌护甲，上限 0.85）
压制减伤（镇岳刀光环等）= 与 DR 相加后 clamp 到 0.90
```
| 护甲 A | DR |
|---|---|
| 25 | 20% |
| 50 | 33% |
| 100 | 50% |
| 200 | 67% |
| 400 | 80% |

### 7. 全局难度系数
| 场景 | 系数 |
|---|---|
| 普通/精英 | 1.00 |
| Boss | 1.00（Boss 靠血量与机制抗压，不吃减伤） |
| （预留）低难度模式 | 0.75 |

## 三、DoT（灼烧/中毒/冰缓）规则

| DoT | 叠层 | 每层效果 | 刷新 |
|---|---|---|---|
| 灼烧（火） | 最多 5 层 | 每秒 A_dao×8% 火伤 | 命中刷新全部层，每层独立 3s |
| 中毒（毒） | 最多 5 层 | 每秒 A_dao×10% 毒伤 | 同上 |
| 冰缓（水） | 不叠层 | 敌移速 −30%、攻速 −20%，2s | 命中刷新 |
- DoT **不吃**暴击/部位/克制（仅吃基础 A_dao），吃全局系数。
- 血饮刀吸血 = 灼烧实际伤害 × 30%。

## 四、雷链（惊雷刃）
```
触发：该刀打出暴击 → 链式跳跃至最近 3 个敌人（半径 5 单位内）
伤害 = 本次伤害 × 50%（每跳衰减 20%：50% → 40% → 32%）
```

## 五、收势伤害
```
收势伤害 = Σ(全部刀 A_dao × 1.6) × 2.0 × 属性克制（按各自系别逐刀结算）
附加：击退 2 单位 + 0.3s 眩晕
```

## 六、数值自检表（防膨胀红线）

| 校验 | 目标 |
|---|---|
| 学徒期（6 斤全 1 斤刀）DPS | ~18-25（域 1 小兵 30-50 血，2-3s/只） |
| 名匠期（15 斤混搭）DPS | ~55-80（域 3 小兵 90-140 血） |
| 至尊期（36 斤成型橙阵）DPS | ~220-320（域 5 小兵 250-400 血） |
| 玩家 TTK（被小兵围殴致死） | ≥ 8s（留给走位容错） |
| 普通节点时长 | 25-45s |
| 精英节点时长 | 40-70s |
| Boss 战时长 | 域1 60-80s / 域2 70-95s / 域3 80-110s / 域4 90-125s / 域5 110-150s |

> v1.3：DPS 目标平滑（中后期不再过猛）；Boss 战由"2-4 分钟"缩短为 60-150s 区间，通过血量+阶段机制+输出窗口共同达成，而非纯堆 HP。
> 每次改刀面板攻击后必须跑此表自检，改动记录进 [INDEX 版本记录](../00-INDEX.md)。
