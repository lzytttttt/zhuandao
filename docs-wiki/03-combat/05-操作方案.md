# 操作方案（设计红线 · 最先定稿）

> 上级：[战斗总纲](./00-战斗总纲.md) ｜ 本文件为全项目**最高优先级约束**，任何新设计与本文件冲突即打回。

---

## 红线（不可违反）

**全游戏仅使用鼠标左键（触摸屏单指）。**

- 零键盘、零右键、零中键、零滚轮（滚轮仅允许页面滚动，不作为游戏输入）、零组合键、零长按双击手势、零 QTE。
- 不存在"第二技能键"。一切主动效果要么自动（收势），要么是走位的结果。

## 输入映射总表（全量，只有这么多）

| 场景 | 输入 | 反馈 |
|---|---|---|
| 战斗内 | **按住左键** | 角色向鼠标位置移动（到达鼠标点或松开即停） |
| 战斗内 | 松开左键 | 角色减速停下（0.1s 内） |
| 节点地图 | 点击节点 | 进入该节点 |
| 商店/事件 | 点击选项 | 确认 |
| 刀架（局外） | 按住左键拖拽刀 | 上阵/下阵（拖到刀架槽位） |
| 锻造/淬火 | 点击按钮 | 确认 |
| 通用 | 悬停 | Tooltip（延迟 0.3s） |
| 暂停 | 点击屏幕右上角"⏸"按钮 | 战斗暂停（战斗内ESC亦兼容，但**不作为必须路径**） |

## 战斗内移动细则

```
目标点 = 鼠标指针世界坐标
移动逻辑：
  if 按住左键:
    朝目标点移动，速度 = 玩家移速
    距目标点 < 0.2 单位时贴齐
  else:
    速度衰减至 0（0.1s）
```

- 鼠标指针距离角色 > 6 单位时，指针处显示小箭头（方向指示，弱化"盯指针"疲劳）。
- **指针不遮挡判断**：角色脚下常驻淡光圈标识本体位置（俯视 2D 刀阵晃眼时的锚点）。

## 收势的自动化（v1.2 决策落地）

- 收势**能量满自动释放**，无任何手动触发方式（不走位也能打出，但炸点=玩家当前位置）。
- 走位与收势的协同 = 本游戏操作上限：**聚怪 → 引爆**。
- 屏幕上方常驻收势能量条（8s 充满一圈，满时"嗡"一声提示 + 角色泛光 0.5s 前摇演出，玩家有时间最后微调站位）。

## 可访问性（顺带收益）

| 配置 | 默认 | 说明 |
|---|---|---|
| 指针轨迹提示 | 开 | 移动方向微箭头 |
| 命中停顿（hit-stop） | 开（≤0.05s） | 手感 |
| 屏幕震动 | 中 | 可关 |
| 色盲模式 | 关 | 属性克制色环改用形状标记 |

## UI 布局（仅左键约束下的布局原则）

1. 一切可交互元素 ≥ 48×48px（触屏兼容）。
2. 战斗内 HUD 元素**不重叠指针高频路径**（中央区域）：血条/能量条贴顶，小地图/波次贴角。
3. 悬停即出 Tooltip，不依赖右键。
4. 危险警示（红圈/扇形）全部地面渲染，不依赖 UI。
