## 一、字段定义

| 字段 | 类型 | 说明 |
|---|---|---|
| id | string | 全局唯一，前缀 dao_ |
| name | string | 中文名（全局唯一） |
| sys | enum | 系别：风/火/水/毒/雷/刚/玄 |
| weight | int | 重量（斤）1-5 |
| rarity | enum | 白/绿/蓝/紫/橙 |
| atk | int | 基础攻击（A_dao） |
| spin | float | 自旋速度（圈/s） |
| orbit | float | 公转速度（圈/s） |
| radius | float | 公转半径（单位） |
| trait | string | 特性 ID（见二节） |
| affix_pool | string[] | 词缀池（见 [词缀库](../04-build/01-刀词缀库.md)） |
| drop_domain | int[] | 可掉落域 |
| price | int | 商店售价（金） |

| burn_leech | 汲血 | 灼烧伤害 30% 转玩家回血 | — |
| ignore_block | 破格挡 | 无视格挡与弹开判定 | — |
