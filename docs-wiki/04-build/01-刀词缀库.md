# 刀词缀库

> 上级：[构筑总纲](./00-构筑总纲.md) ｜ 稀有度规则见 [稀有度与合成](./04-稀有度与合成.md)。

---

## 规则

1. 每把刀有 **1-3 条词缀**（白 1 条 / 绿 1 条 / 蓝 2 条 / 紫 2 条 / 橙 3 条）。
2. 词缀分五类：**速度 / 范围 / 攻击 / 重心 / 特效**。重心类为本作特色（调整刀身/刀尖伤害占比）。
3. 词缀数值为固定档位（不做随机区间，方便配置化）。
4. 获取：掉落自带 / 商店购买 / 祭坛强化 / 局外淬火重铸。
5. 同一条词缀同名不叠加（两把刀各带"疾风 I"→ 各自生效，作用于各自刀）。
6. **乘区红线（v1.3）**：单条普通词缀收益 8%~15%，紫词缀 12%~18%，专属词缀 15%~25%。攻击类词缀按此红线校准；速度/范围类词缀字面百分比 ≠ DPS 收益（速度影响命中频率、半径影响覆盖），保留其档位。

## 词缀与刀的适配（词缀池）

每把刀有专属词缀池（见 [全刀种清单](../07-content/00-全刀种清单.md) 末列），约束：
- 重刀（4-5 斤）不出现"疾风"（速度词缀是轻刀特权，保住重量档位差异）。
- 特效词缀与刀系别相同者优先入池（火褶刀优先"燃刃"）。
- 橙刀 3 条词缀中必有 1 条专属词缀（两仪刀专属"瞬发"、镇岳刀专属"震荡"等）。

## 淬火重铸（局外改词缀）

- 消耗：目标刀 1 条词缀 + 重铸材料（百炼钢×2）+ 金币（稀有度×10）。
- 结果：从该刀词缀池中**随机替换**该条（可锁定另 1 条不动的成本×3）。
- 详见 [锻造系统](../06-progression/01-铁匠锻造系统.md)。
