## 战斗形态

- **视角**：俯视 2D，固定单屏竞技场（无卷轴滚动，屏幕即战场）。
- **操作**：仅鼠标左键（走位），其余全自动。详见 [操作方案](./05-操作方案.md)。
- **战场尺寸**：约 22×14 单位（1 单位 = 64px，待调参），边界为擂台式空气墙。
- **单场时长**：普通战斗 30-90s；精英 +50%；Boss 战 2-4 分钟。

## 战斗实体模型

| 实体 | 字段（最小集） | 说明 |
|---|---|---|
| 玩家 | 位置/生命/移速/负重 | 唯一可控实体，碰撞体为圆（r=0.4） |
| 刀 | 归属/角度/自旋速度/公转半径/伤害/词缀 | 挂在玩家身上的攻击单元，见 [转刀机制](./01-转刀机制.md) |
| 敌人 | 位置/生命/护甲/行为树/掉落 | 见 [敌人AI与行为](./04-敌人AI与行为.md) |
| 飞行物 | 归属/轨迹/伤害 | 敌人远程攻击（鱼叉/水弹等），均可被刀摧毁 |
| 掉落物 | 内容/拾取半径 | 金币（自动吸附）、材料/刀（走近拾取） |

## 战斗流程

```
进入房间 → 0.5s 敌人入场演出 → 战斗开始
  → 玩家左键走位，刀阵自动旋转攻击
  → 敌人按行为树索敌/攻击
  → 收势能量满 → 自动收势（AOE 爆发）
  → 敌人全灭 → 掉落结算 → 3s 后回节点地图
玩家生命归零 → 死亡结算（见核心循环）
```

## 玩家基础数值

| 属性 | 基础值 | 成长 | 备注 |
|---|---|---|---|
| 生命 | 100 | 每境界 +30 | 见境界体系 |
| 移速 | 6 单位/s | 不随境界增长 | 只能靠词缀提升 |
| 碰撞体 | 圆 r=0.4 | 固定 | 玩家本体无碰撞伤害 |
| 收势能量 | 100 点 | 见转刀机制 | 自动充能自动释放 |

## 敌我交互原则

1. **玩家不直接造成伤害**——伤害全部来自刀（含收势）。走位是唯一防守与进攻 positioning。
2. **敌人的攻击均可躲避**（前摇≥0.5s）或**可被刀摧毁**（飞行物），保证"走位"有正反馈。
3. 敌人之间不互相伤害，不阻挡彼此移动（仅对玩家有推挤）。
4. 刀的碰撞**不打断敌人攻击前摇**（重刀"击退"类词缀除外）。

## 性能预算（技术约束）

- 同屏敌人 ≤ 40，同屏刀 ≤ 8，飞行物 ≤ 60，粒子 ≤ 200。
- 碰撞检测：空间哈希网格（cell=1.0 单位），每帧全量刷新。
- 目标帧率 60fps（Canvas 2D，详见计划文档第九节技术栈）。
