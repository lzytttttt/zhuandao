行 = 生产者（供血），列 = 消费者（吃血）。✓ = 行系统给列系统供血。

|---|---|---|---|---|---|
| **战斗**（掉落） | — | ✓ 掉刀/词缀 | ✓ 通行节点 | ✓ 材料/金币 | ✓ 材料 |
| **构筑**（刀阵强度） | ✓ 决定 DPS | — | ✓ 过 Boss 资格 | — | — |
| **分域**（域解锁） | ✓ 高级敌人池 | ✓ 高级掉落池 | — | ✓ 淬体材料 | ✓ 高级配方材料 |
| **成长**（境界/负重） | ✓ 生命 | ✓ 负重预算 | ✓ 入域资格 | — | ✓ 高级锻造资格 |
| **锻造**（造刀/重铸） | — | ✓ 新刀/新词缀 | — | — | — |
| **声望** | — | — | ✓ 解锁域 | ✓ 淬体门槛 | — |

## 三、硬依赖（缺一不可）

| 依赖 | 说明 | 断链后果 |
|---|---|---|
| 负重 ← 境界 | 编队预算完全由境界决定 | 构筑失去成长感 |
| 材料 ← 域 | 淬体材料按域分层 | 声望解锁失去意义 |
| 刀 ← 清单 | 一切刀数值源自 [全刀种清单](../07-content/00-全刀种清单.md) | 数值漂移、双源冲突 |
| 克制 ← 属性环 | 战斗/构筑针对性完全依赖五行环 | 流派无优劣、选路无脑 |
| 走位 ← 收势 | 大招炸点=玩家位置 | 收势无操作深度 |

## 四、软依赖（可调平衡）

| 依赖 | 调节空间 |
|---|---|
| Boss 强度 ← DPS 自检表 | 伤害公式红线（[自检表](../03-combat/03-伤害公式.md)）|
| 经济 ← 一域收入 40-70 金 | 商店定价/掉率的总锚 |
| 事件奖励 ← 经济锚 | 30-50 金档位不破锚 |
| 声望曲线 | 各门槛 100/250/500/900/1500 可整体缩放 |

## 五、版本扩展挂点（预留，不实现）

| 想加什么 | 挂在哪 |
|---|---|
| 新刀种 | [刀种清单](../07-content/00-全刀种清单.md) 追加行 + 词缀池 |
| 新 Boss/域 | 域 6 追加（黑风崖之后），材料/声望曲线顺延 |
| 新流派 | 新系别（如"音"）→ 属性环插入（需重平衡）或做玄系式规则刀 |
| 周目 NG+ | 品阶路线终局节点 |
| 局外天赋 | 成长总纲"不做的事"解禁 |
