## 循环的关键节拍

| 节拍 | 时长 | 玩家做什么 | 心流 |
|---|---|---|---|
| 一场战斗 | 30-90 秒 | 仅左键走位，看刀阵割草 | 释放/爽 |
| 一段节点路线 | 5-10 分钟 | 选路、买刀、赌事件 | 决策/赌 |
| 一域通关 | 30-60 分钟 | Boss 考验构筑成型度 | 挑战/成就感 |
| 一轮局外整备 | 3-5 分钟 | 锻造/重铸/编队/升境界 | 规划/期待 |

## 四系统互喂（为什么循环转得动）

1. **战斗 → 构筑**：战斗掉词缀和刀，让下一场刀阵更强（割草更爽）。
2. **构筑 → 爬塔**：流派成型才能过 Boss；过 Boss 才解锁高级节点。
3. **爬塔 → 成长**：高级域掉高级材料，材料是锻造和升境界的唯一硬通货。
4. **成长 → 战斗**：境界提升负重 → 带更多/更重的刀 → 新流派可玩 → 战斗手感质变。

> 任何新系统设计必须回答："它给循环里哪一环供血？"——见 [系统依赖图](../08-systems-connections/00-系统依赖图.md)。

## 失败循环（死亡处理）

- 单局内收集的**刀**：清空（含局内购买的）。
- 单局内收集的**金币/材料**：按 50% 结算回铁匠铺。
- **词缀图鉴解锁、境界、声望、已锻造入库的刀**：永久保留（入库刀 = 已在刀架注册的刀，死亡不清）。
- 死亡文案示例："刀断了，炉火还热着。—— 回铁匠铺重来"
