## 材料（6 种）

| 材料 | 产出域 | 用途 |
|---|---|---|
| 百炼钢 | 全域通用 | 重铸词缀 / 低阶配方 |
| 玄铁矿 | 域 1-2 | 绿/蓝刀配方 |
| 寒水玉 | 域 3 | 蓝/紫刀配方 / 淬体（名匠→宗师） |
| 赤炎髓 | 域 2-4 | 火系刀配方 / 词缀"燃刃"升级 |
| 大漠金砂 | 域 4 | 紫/橙刀配方 / 淬体（宗师→刀圣） |
| 黑崖陨铁 | 域 5 | 橙刀配方 / 淬体（刀圣→至尊） |

## 锻造台（造刀）

```
配方 = 刀谱（图鉴解锁） + 材料 + 金币
产出 = 该刀（白阶起）+ 随机 1 条词缀（该刀词缀池）
```

| 锻造档 | 刀稀有度 | 材料示例 | 金币 |
|---|---|---|---|
| 粗锻 | 白 | 百炼钢×2 | 5 |
| 细锻 | 绿 | 玄铁矿×2 + 百炼钢×2 | 10 |
| 精锻 | 蓝 | 玄铁矿×4 + 寒水玉×1 | 20 |
| 大师锻 | 紫 | 寒水玉×3 + 大漠金砂×2 | 40 |
| 传说锻 | 橙 | 大漠金砂×5 + 黑崖陨铁×3 | 80 |

- **刀谱解锁**：抄录事件残页 / 掉落即解锁 / Boss 首通送（橙刀谱：剑无极首通自选）。
- 同一刀可重复锻造（同名卡合成需要）。
- 锻造产出固定白阶起步——升档靠**三合一合成**（[合成](../04-build/04-稀有度与合成.md)）。
- **稀有度两层模型**：锻造产出的是 weapon_instance（带稀有度+词缀），刀种（weapon_type）只定义基础属性与词缀池，见 [稀有度与合成](../04-build/04-稀有度与合成.md) 〇节。

## 淬火池（词缀重铸）

| 淬火池等级 | 解锁境界 | 功能 |
|---|---|---|
| 一 | 学徒 | 重铸 1 条词缀（百炼钢×2 + 金币） |
| 二 | 铸师 | 可锁定另 1 条不重铸（材料×3） |
| 三 | 名匠 | 定向重铸（限定五类之一：速度/范围/攻击/重心/特效，材料×5） |

- 重铸 = 从该刀词缀池**重新随机**（可能出重复前值，赌点所在）。
- 特殊材料加成：赤炎髓×1 可定向"燃刃"类（火刀专用淬火）。

## 铁匠铺经济锚点

| 行为 | 消耗 | 说明 |
|---|---|---|
| 锻一把白刀 | ~5 金 + 钢×2 | 前期主要金币去向 |
| 锻一把紫刀 | ~40 金 + 稀有材料 | 中期目标感 |
| 重铸一次 | ~10-30 金 | 词缀毕业的最后一块拼图 |
| 一域收入 | 40-70 金 + 材料 | 平衡基准（见 [稀有度经济](../04-build/04-稀有度与合成.md)） |

## 操作（仅左键）

- 全部为点击流：选配方 → 确认 → 演出（0.8s 打铁音效+火花）→ 出刀入架。
- 淬火：选刀 → 选词缀（点击高亮）→（可选）锁定 → 确认。
- 拖刀上阵：按住左键从刀架拖到上阵槽（详见 [操作方案](../03-combat/05-操作方案.md)）。
